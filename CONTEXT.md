# Glosario del dominio

## Caso de harvesting

Registro operativo que agrupa, en una misma jornada, una o varias series donantes y las piezas recuperadas de cada una. Un caso conserva fecha, operador y observaciones generales.

## Serie donante

Equipo individual elegible por encontrarse en estado Scrap o Irreparable, del cual se retiran piezas. Toda pieza recuperada debe quedar asociada a exactamente una serie donante.

## Línea recuperada

Registro de un SKU extraído de una serie donante. Una serie solo puede aportar una unidad de cada SKU dentro de un caso de harvesting; el mismo SKU no puede repetirse para esa serie. Cuando la captura abarca varias series, la cantidad total del SKU equivale como máximo al número de series incluidas y se distribuye como una unidad trazable por serie. Su registro incrementa exclusivamente el stock recuperado de Bodega de Partes y conserva la trazabilidad del origen.
